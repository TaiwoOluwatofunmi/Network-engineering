## 👋 About This Portfolio

Welcome to my Network Engineering Portfolio.

This repository serves as a central collection of my practical networking projects, laboratory exercises, configurations, technical documentation, and experiments.

My focus is on developing practical skills in enterprise networking, routing and switching, network troubleshooting, network security, and network automation.

Through hands-on projects and continuous learning, I aim to strengthen my understanding of networking technologies and build the technical competence required for professional Network Engineering roles.

## 🎯 Technical Areas of Focus

- **Networking Fundamentals:** OSI and TCP/IP models, IP addressing, subnetting and network protocols.
- **Routing and Switching:** VLANs, trunking, inter-VLAN routing, static routing and dynamic routing concepts.
- **Network Infrastructure:** Routers, switches, network topology design and configuration.
- **Network Troubleshooting:** Connectivity testing, packet analysis and fault identification.
- **Network Security:** Access Control Lists (ACLs), network segmentation and traffic filtering.
- **Network Automation:** Python, scripting and automation of network tasks.
